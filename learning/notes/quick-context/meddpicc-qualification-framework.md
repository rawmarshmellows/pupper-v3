# MEDDPICC Qualification Framework

> **Related:** [[learning/notes/quick-context/miller-heiman-strategic-selling-lamp]] | [[learning/notes/quick-context/post-sale-account-engagement]] | [[learning/notes/quick-context/sales-methodology-layering]] | [[learning/notes/quick-context/strategic-selling-buyer-roles]] | [[learning/notes/quick-context/sandler-kare-segmentation]]

> **TL;DR:** MEDDPICC is an 8-element deal qualification checklist (Metrics, [[learning/notes/quick-context/playbook-main|Economic Buyer]], Decision Criteria, Decision Process, Paper Process, Identify Pain, Champion, Competition) used by enterprise SaaS companies to rigorously assess [[learning/notes/quick-context/differential-pair|whether]] a deal is winnable before investing significant sales resources.

## The Core Problem

Sales teams [[learning/notes/quick-context/3d-printing-filament-refill-vs-spool|waste]] enormous effort on deals that were never going to close. Reps spend months nurturing opportunities [[learning/notes/quick-context/comparator-specification|only]] to discover at [[learning/notes/quick-context/capacitance|the]] 11th hour that there's no budget, the wrong stakeholder was engaged, or a competitor had an insurmountable advantage. Without a systematic qualification framework, pipeline becomes fiction—inflated with "opportunities" that have no realistic path to revenue.

## 5 Essential Terms

| Term | [[learning/notes/quick-context/capacitance|Definition]] |
|------|------------|
| **Metrics** | The quantifiable business outcomes the customer expects; "success" defined in numbers they'll measure you against |
| **Economic Buyer** | The single person with discretionary authority to spend the money—[[learning/notes/micro-context/can-bus-termination|not]] a committee, but the individual who [[learning/notes/quick-context/embedded-communication-protocols|can]] say "yes" alone |
| **Champion** | An internal advocate with [[learning/notes/quick-context/d-flip-flop|power]] [[learning/notes/micro-context/push-pull-vs-open-drain|and]] influence who actively sells on [[learning/notes/quick-context/mcp6541-as-lmc7211-replacement|your]] behalf [[learning/notes/quick-context/bare-minimal-data-storage-circuit|when]] you're not in the room |
| **Paper Process** | The legal, procurement, security, and administrative steps between verbal agreement and signed contract |
| **Decision Process** | The sequence of events, approvals, and stakeholders between "interested" and "decision made" |

<summary><strong>How It Works</strong> — The 8 elements as qualification gates</summary>

MEDDPICC creates a checklist that forces reps to validate—not assume—each element:

```
┌────────────────────────────────────────────────────────────────────────┐
│                         MEDDPICC ELEMENTS                               │
├────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  M ─ METRICS              "What numbers define success for them?"       │
│  │   ├─ Revenue impact?                                                 │
│  │   ├─ Cost savings?                                                   │
│  │   └─ KPIs they'll measure?                                           │
│  │                                                                      │
│  E ─ ECONOMIC BUYER       "Who can write the check alone?"              │
│  │   ├─ Have you met them?                                              │
│  │   ├─ Do they know about you?                                         │
│  │   └─ Are they engaged?                                               │
│  │                                                                      │
│  D ─ DECISION CRITERIA    "What are they evaluating against?"           │
│  │   ├─ Technical requirements?                                         │
│  │   ├─ Business requirements?                                          │
│  │   └─ Can you influence the criteria?                                 │
│  │                                                                      │
│  D ─ DECISION PROCESS     "What happens between now and signature?"     │
│  │   ├─ Who's involved?                                                 │
│  │   ├─ What sequence?                                                  │
│  │   └─ What timeline?                                                  │
│  │                                                                      │
│  P ─ PAPER PROCESS        "What's between 'yes' and signed contract?"   │
│  │   ├─ Legal review?                                                   │
│  │   ├─ Procurement?                                                    │
│  │   ├─ Security/compliance?                                            │
│  │   └─ How long does each take?                                        │
│  │                                                                      │
│  I ─ IDENTIFY PAIN        "What business problem are we solving?"       │
│  │   ├─ Is it urgent?                                                   │
│  │   ├─ What's the cost of inaction?                                    │
│  │   └─ Is it their #1 priority?                                        │
│  │                                                                      │
│  C ─ CHAMPION             "Who's selling for us inside?"                │
│  │   ├─ Do they have power?                                             │
│  │   ├─ Do they have influence?                                         │
│  │   └─ Are they actively advocating?                                   │
│  │                                                                      │
│  C ─ COMPETITION          "Who else are they considering?"              │
│      ├─ Vendors?                                                        │
│      ├─ Build vs. buy?                                                  │
│      └─ Do nothing?                                                     │
│                                                                         │
└────────────────────────────────────────────────────────────────────────┘
```

**Scoring Example:**

Most teams score each element 0-3:
- **0** = Unknown/not validated
- **1** = Identified but weak
- **2** = Validated and moderate
- **3** = Confirmed and strong

A deal with [[learning/notes/quick-context/similarity-transform|total]] score <12 [[learning/notes/micro-context/push-pull-vs-open-drain|out]] of 24 should not be in commit forecast.

**The Critical Distinction: Champion vs. [[learning/notes/quick-context/playbook-main|Coach]]**

```
COACH (from Miller Heiman)          CHAMPION (MEDDPICC)
═══════════════════════════         ═══════════════════════
Provides information                Takes action
Tells you what's happening          Makes things happen
May lack organizational power       Has power AND influence
Helps you understand                Helps you WIN
"They're evaluating 3 vendors"      "I scheduled you with the CFO"
```

A Coach is valuable but insufficient. A Champion actively spends political capital on your behalf.

<summary><strong>[[learning/notes/quick-context/3d-printing-filament-types|The Key Tension]]</strong> — Rigor vs. velocity</summary>

MEDDPICC creates friction by design—it slows down unqualified deals. The tension:

| High Rigor | High Velocity |
|------------|---------------|
| Every element validated | Quick qualification calls |
| Fewer deals in pipeline | Larger pipeline coverage |
| Higher win rates | More at-bats |
| Longer average cycle | Some winners slip through |
| Works for $100K+ ACV | Works for high-[[learning/notes/quick-context/cnc-machining|volume]] SMB |

**The practitioner debate:** Enterprise sales leaders argue unvalidated pipeline is worse than useless—it creates false forecasts and misallocated resources. Velocity-focused leaders counter that over-qualification kills momentum and some deals are won through hustle, not process.

**The research:** Studies show 41% higher win rates and 26% shorter cycles for consistent MEDDPICC users. The rigor pays [[learning/notes/quick-context/bjt-specifications|off]] for deals above ~$25K ACV where the [[learning/notes/quick-context/bond-pad|cost]] of losing a qualified deal exceeds the cost of qualification time.

<summary><strong>Test Your Understanding</strong> — 5 progressive questions</summary>

**Q1:** What does the second "P" in MEDDPICC stand for and [[learning/notes/quick-context/atoms-molecules-polymers-basics|why]] was it added?
<details>
<summary>Answer</summary>
Paper Process—the legal, procurement, and administrative steps between verbal "yes" and signed contract. It was added because enterprise deals often stall in procurement for weeks or months, and reps who don't map this process miss close dates. See: 5 Essential Terms.
</details>

**Q2:** A rep says "I have a great Champion—she's given me tons of insider info about their process." What question should you ask?
<details>
<summary>Answer</summary>
"What has she *done* to advance the deal?" Information-giving is Coach behavior. A Champion takes [[learning/notes/quick-context/pupper-lab5-neural-controller|action]]: schedules meetings with the Economic Buyer, lobbies internally, fights for budget. The test is action, not access. See: How It Works, Champion vs. Coach.
</details>

**Q3:** Your deal scores 20/24 on MEDDPICC but you haven't identified Competition. Why is this still a red flag?
<details>
<summary>Answer</summary>
Competition includes "do [[learning/notes/quick-context/tlv7211-as-lmc7211-replacement|nothing]]"—if you don't know what alternatives they're considering (including status quo), you can't differentiate or create urgency. A deal with high scores elsewhere but unknown competition might lose to inertia or a vendor you never saw coming.
</details>

**Q4:** Why would a company using MEDDPICC still lose winnable deals?
<details>
<summary>Answer</summary>
MEDDPICC qualifies deals but doesn't teach you how to sell. You might have perfect information about the Decision Process but execute poorly in meetings. MEDDPICC pairs with selling methodologies like [[quick-context/challenger-sale-methodology|Challenger]] or SPIN that guide customer interactions.
</details>

**Q5:** A [[learning/notes/quick-context/firmware|startup]] founder says "MEDDPICC is overhead we can't afford at our stage." When would you agree vs. disagree?
<details>
<summary>Answer</summary>
Agree if: ACV <$10K, sales cycle <30 days, high volume. The qualification overhead exceeds the cost of losing some deals. Disagree if: ACV >$25K, complex multi-stakeholder sales, limited sales capacity. Here, wasting months on unwinnable deals is more expensive than qualification time. The framework can be simplified (MEDDIC without [[learning/notes/quick-context/bjt-specifications|both]] Ps) but the mental model of systematic qualification should always apply.
</details>
