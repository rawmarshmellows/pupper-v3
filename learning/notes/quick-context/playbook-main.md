# Existing Account Management Playbook

> A step-by-step guide for managing and growing accounts using KARE Segmentation as the primary classification, synthesized with Miller Heiman LAMP, McDonald KAM Model, Challenger methodology, and Post-Sale Engagement frameworks.

---

## How to Use This Playbook

This playbook is designed to be followed sequentially for each account, then maintained through regular rituals. Work through Steps 1-6 when onboarding a new account or taking over an existing one, then use the Ongoing Rituals section to maintain momentum.

**Linked Databases:** This playbook works with several database templates (imported separately as CSVs). Link them to your account pages for full functionality.

## Step 1: Segment the Account (KARE)

**Goal:** Classify the account into Keep, Attain, Recapture, or Expand to determine time and resource allocation.

### 1.1 Classify Using KARE

```
┌────────────────────────────────────────────────────────────────────────┐
│                         KARE PORTFOLIO VIEW                            │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                    EXISTING RELATIONSHIPS                              │
│            ┌───────────────────┬───────────────────┐                   │
│            │                   │                   │                   │
│   PROTECT  │      KEEP         │      EXPAND       │  GROW             │
│   REVENUE  │                   │                   │  REVENUE          │
│            │  Core accounts    │  Existing custs   │                   │
│            │  Stable revenue   │  Whitespace       │                   │
│            │  Defend from      │  opportunities    │                   │
│            │  competitors      │                   │                   │
│            │                   │                   │                   │
│            ├───────────────────┼───────────────────┤                   │
│            │                   │                   │                   │
│            │    RECAPTURE      │      ATTAIN       │  NEW              │
│            │                   │                   │  RELATIONSHIPS    │
│            │  Lost customers   │  New logos        │                   │
│            │  Changed          │  Greenfield       │                   │
│            │  circumstances    │  prospecting      │                   │
│            │                   │                   │                   │
│            └───────────────────┴───────────────────┘                   │
│                                                                        │
│                    NEW/RE-ESTABLISHED RELATIONSHIPS                    │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

**Key Questions:**
- Is this an existing customer or a new/lost prospect?
- If existing: Is there whitespace to expand, or are we at full usage?
- If lost/former: Have circumstances changed (new buyer, competitor failed)?
- If new: Does it fit ICP? Is there an identified pain or trigger?

### 1.2 KARE Classification

| Classification | Definition | Focus |
|---|---|---|
| **KEEP** | Existing customer, stable revenue, at/near full usage, no major expansion path | Protect from churn, defend from competitors |
| **ATTAIN** | Net-new logo, never bought from us, fits ICP | Win new business, land the account |
| **RECAPTURE** | Former customer or lost deal, circumstances have changed | Re-engage based on new triggers |
| **EXPAND** | Existing customer with whitespace (new depts, products, users) | Grow revenue within the account |

### 1.3 Engagement Levels by KARE Segment

| Segment | Named CSM | Touchpoint Frequency | QBR Frequency | Typical Time % |
|---|---|---|---|---|
| KEEP | Dedicated | Monthly | Quarterly | 20-30% |
| ATTAIN | AE-owned | Prospecting cadence | N/A (pre-sale) | 20-30% |
| RECAPTURE | AE-owned | Trigger-based | N/A (re-engagement) | 10-15% |
| EXPAND | Shared | Bi-weekly | Semi-annual | 30-40% |

### 1.4 When to Use KARE vs. Value/Potential Matrix

**Two frameworks, different purposes:**

| Framework | Question It Answers | When to Use |
|---|---|---|
| **KARE** | What motion am I running? (Defend, Hunt, Re-engage, Grow) | Portfolio allocation, deciding where to spend time |
| **Value/Potential Matrix** | How much engagement does this customer deserve? | Determining CSM investment for existing customers |

**How they work together:**

For existing customers (KEEP and EXPAND), layer the Value/Potential matrix to determine engagement intensity:

```
                    LOW GROWTH          HIGH GROWTH
                    POTENTIAL           POTENTIAL
                ┌─────────────────┬─────────────────┐
HIGH CURRENT    │                 │                 │
VALUE           │    PROTECT      │    STRATEGIC    │
                │   (KEEP)        │   (EXPAND)      │
                ├─────────────────┼─────────────────┤
LOW CURRENT     │                 │                 │
VALUE           │    MAINTAIN     │    GROWTH       │
                │   (KEEP)        │   (EXPAND)      │
                └─────────────────┴─────────────────┘
```

- **KEEP accounts** land in Protect (high value, defend) or Maintain (low value, efficient)
- **EXPAND accounts** land in Strategic (high value + potential) or Growth (low value but high potential)
- **ATTAIN/RECAPTURE** are pre-sale motions—use sales qualification (MEDDPICC) instead

**Decision flow:**
1. **First:** Assign KARE category (portfolio motion)
2. **Then:** For KEEP/EXPAND, assess Value/Potential (engagement intensity)
3. **Result:** Know both *what* you're doing and *how much* to invest

### 1.5 Internal Revenue KPIs

Track these metrics to measure account management effectiveness:

| Metric | Definition | Target |
|---|---|---|
| **Gross Revenue Retention (GRR)** | Revenue retained excluding expansion (churned $/starting $) | >90% |
| **Net Revenue Retention (NRR)** | Revenue retained including expansion and contraction | >110% |
| **Expansion Revenue %** | New revenue from existing customers / total new revenue | >30% |
| **Logo Retention** | Customers retained / customers at start of period | >85% |
| **Time to First Expansion** | Days from initial close to first expansion deal | <365 days |

**By KARE Segment:**

| Segment | Primary KPI | Secondary KPI |
|---|---|---|
| **KEEP** | GRR, Logo Retention | NPS, Health Score |
| **EXPAND** | Expansion Revenue, NRR | Whitespace Penetration |
| **ATTAIN** | New Logo Count, New ARR | Win Rate, Sales Cycle Length |
| **RECAPTURE** | Win-back Rate, Recaptured ARR | Time to Re-engage |

## Step 2: Diagnose Relationship Maturity

**Goal:** Understand where the relationship actually stands.

### McDonald KAM Model - Five Stages

| Stage | Characteristics | Focus Question |
|---|---|---|
| **EXPLORATORY** | Testing fit, limited trust, no commitment | "Can we work together?" |
| **BASIC** | Transaction-focused, price-driven, low switching costs | "What's the cost?" |
| **COOPERATIVE** | Preferred supplier, sharing information, multiple contacts | "How can we work better?" |
| **INTERDEPENDENT** | Joint planning, high switching costs, shared goals | "How do we grow together?" |
| **INTEGRATED** | One organization, joint P&L, mutual dependency | "We win or lose together" |

### Relationship Pattern Assessment

**Bow-Tie (Fragile):**
- Single point of contact on each side
- If that person leaves, relationship breaks
- Information bottleneck

**Diamond (Resilient):**
- Multiple connections at multiple levels
- Relationship survives personnel changes
- Rich information flow

## Step 3: Map Stakeholders (Miller Heiman LAMP)

**Goal:** Identify all players who influence decisions and renewals.

### The Four Buyer Roles

| Role | Definition | Key Question |
|---|---|---|
| **Economic Buyer** | Final authority to approve spending. Can say yes when everyone says no. | "Who controls the budget?" |
| **User Buyer** | Day-to-day users who judge success by job impact | "Whose life improves?" |
| **Technical Buyer** | Screens against specs/compliance. Can veto but not approve. | "Who can block us?" |
| **Coach** | Internal advocate who provides intel and guides strategy | "Who's helping us win?" |

### Stakeholder Stance Definitions

| Stance | Meaning | Your Approach |
|---|---|---|
| **GROWTH** | Sees opportunity to win/advance | Fuel their vision, make them the hero |
| **TROUBLE** | Current situation is painful | Emphasize relief, show quick wins |
| **EVEN KEEL** | Not feeling acute pain or opportunity | Create urgency, highlight hidden costs |
| **OVERCONFIDENT** | Believes current approach is fine | Bring data that challenges assumptions |

## Step 4: Create the Account Plan

**Goal:** Define what success looks like and how to get there.

### 4.1 Charter Statement Template

Write a customer-centric statement of what you're trying to achieve FOR them:

> "[Customer name]'s [team/division] will achieve [specific outcome] within [timeframe] by [how], resulting in [measurable benefit]."

**Validation checklist:**
- Could the customer present this to their leadership as THEIR initiative?
- Is the outcome specific and measurable?
- Does it tie to their strategic priorities?

### 4.2 Situation Appraisal Questions

- What external pressures are they facing?
- What internal initiatives are underway?
- What changed recently (leadership, funding, strategy)?
- What are the key opportunities?
- What are the key risks?

### 4.3 Competitive Landscape

Always include "Status Quo" (doing nothing) as a competitor. Often the real competition is inaction, not another vendor.

## Step 5: Build the Engagement Plan

**Goal:** Define cadence, touchpoints, and next actions.

### Engagement Model by KARE Segment

**KEEP Accounts (Existing - Protect Revenue):**
- Value review: Monthly
- QBR: Quarterly
- Executive check-in: Semi-annual
- Renewal prep: -90 days
- Competitive monitoring: Continuous

**EXPAND Accounts (Existing - Grow Revenue):**
- Champion call: Bi-weekly
- Usage review: Monthly
- [[learning/notes/quick-context/whitespace-mapping|Whitespace mapping]] session: Quarterly
- Business review: Semi-annual
- Executive alignment: As expansion progresses

**ATTAIN Accounts (New Logo Prospecting):**
- Prospecting cadence: Per sales playbook
- Discovery calls: As scheduled
- Demo/evaluation: As qualified
- *Note: Follow new business sales process*

**RECAPTURE Accounts (Re-engagement):**
- Trigger monitoring: Continuous (job changes, competitor news)
- Re-engagement outreach: When triggers fire
- Discovery refresh: If re-engaged
- *Note: Only pursue when circumstances have genuinely changed*

**Use the Engagement Touchpoints database to schedule and track.**
**Use the 90-Day Action Plan database for immediate planning.**

## Step 6: Prepare Your Challenger Insights

**Goal:** Lead conversations with value, not just check-ins.

### The Teaching Pitch Structure

1. **WARMER** - "Here's what we see in your industry..."
2. **REFRAME** - "But here's what most companies miss..."
3. **RATIONAL DROWNING** - "Here's the cost of the problem you didn't know you had..."
4. **EMOTIONAL IMPACT** - "And here's what happens when this goes wrong..."
5. **NEW WAY** - "Companies solving this do X differently..."
6. **YOUR SOLUTION** - "Here's how we enable that..."

### Tailor by Stakeholder

Each stakeholder has different priorities. Prepare tailored insight angles for:
- Economic Buyer (ROI, cost avoidance)
- User Buyer (job impact, daily pain)
- Technical Buyer (compliance, integration, security)

### Take Control Preparation

Anticipate pushback scenarios:
- Discount requests
- Scope creep
- Timeline stalls
- Wrong stakeholder engagement

## KARE Migration Signals

### Account Movement Triggers

**ATTAIN → EXPAND (New customer lands):**
- Deal closes, customer onboards
- Immediate whitespace identified during sales
- Multiple use cases discussed pre-sale

**ATTAIN → KEEP (New customer lands, limited scope):**
- Deal closes at full usage potential
- No additional departments/products fit
- Stable, contained use case

**EXPAND → KEEP (Expansion complete):**
- Whitespace fully penetrated
- At or near maximum usage
- Relationship mature, no further growth path

**KEEP → EXPAND (New opportunity emerges):**
- Company acquires/merges (new teams)
- New product launched that fits
- Org restructure creates new buyers
- Champion moves to new department

**KEEP/EXPAND → RECAPTURE (Churn occurs):**
- Customer churns
- Lost to competitor
- Budget cut/project cancelled

**RECAPTURE → EXPAND (Win-back succeeds):**
- Re-engagement successful
- New contract signed
- Whitespace available in return

### Churn Risk Signals (KEEP/EXPAND)

- Key stakeholders leave
- Usage declining
- Company in financial trouble
- Relationship becomes transactional
- Competitor gaining traction

## Red Flags Checklist

**Use the Red Flags Checklist database and review monthly.**

### Relationship Risks
- Champion left or changing roles
- Executive sponsor disengaged
- New decision-makers not contacted
- Relationship regressed to Bow-Tie

### Usage Risks
- Login frequency declining
- Feature adoption stalled
- Support ticket volume spiking
- Key users not engaging

### Competitive Risks
- Competitor meetings scheduled
- RFP for our category
- Budget reviews mentioning alternatives
- Procurement asking for benchmarks

### Business Risks
- Company restructuring
- Budget cuts announced
- Strategic priority shifts
- M&A activity

## QBR Guide

**Use the QBR Tracker database for preparation and follow-up.**

### Pre-QBR (1 week before)
- Pull usage metrics and adoption data
- Document value delivered (quantified)
- Prepare 2-3 insights to share
- Prepare expansion proposal if appropriate
- Confirm attendees
- Send pre-read/agenda

### Agenda (60-90 min)
1. Relationship check-in (5 min)
2. Value delivered (15 min)
3. Usage deep-dive (15 min)
4. Industry insight (10 min)
5. Their priorities (15 min)
6. Expansion discussion (15 min)
7. Action items (5 min)

### Post-QBR (within 48 hours)
- Send summary with action items
- Update account plan
- Create follow-up tasks
- Share notes internally

## Quick Reference: When to Use Which Framework

| Question | Framework |
|---|---|
| "What motion am I running?" (Defend/Hunt/Re-engage/Grow) | KARE Segmentation |
| "How much CSM investment for this customer?" | Value/Potential Matrix |
| "Where does this relationship stand?" | McDonald KAM Model |
| "Who should I be talking to?" | Miller Heiman LAMP |
| "What are we trying to achieve?" | LAMP Charter Statement |
| "How should I structure this conversation?" | Challenger |
| "Is this deal real?" | MEDDPICC |

**Layering KARE + Value/Potential:**
1. KARE first → determines portfolio motion (Keep, Attain, Recapture, Expand)
2. Value/Potential second → for existing customers (Keep/Expand), determines engagement level (Strategic, Growth, Protect, Maintain)
