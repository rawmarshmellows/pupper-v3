Communication Protocols

SPIPi ↔ U1 (CS1) + U5 (CS2) shared bus
I2C1Pi ↔ BNO086 (IMU) + ADS1110 (ADC) directly
I2C3Pi pins 8,10 ↔ CN18 external I2C connector
CANMCUs ↔ 4x MAX3051 → 12 servos via CN17
I2SPi → MAX98357A → Speaker (4 pins)
GPIOPi → LED_DIN (NeoPixel) + 2x ear servo PWM
SWDCN1/CN2 ↔ MCU debug (no UART on Pi header)
PWRCN21 → U8 (TPS54561) → L1 → 5V rail; D1 catches SW↔GND; R5/R6 set FB

40-Pin Raspberry Pi Header (U2)
