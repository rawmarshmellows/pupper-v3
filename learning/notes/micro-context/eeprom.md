# EEPROM (Electrically Erasable Programmable Read-Only Memory)

**[[quick-context/capacitance|Definition]]:** A non-volatile memory chip that retains data without [[quick-context/d-flip-flop|power]], can be electrically rewritten byte-by-byte, and is used to store small amounts of configuration data (typically 1 KB – 64 KB). It sits between one-time-programmable ROM (write once) and [[learning/notes/micro-context/sram|SRAM]] (volatile, loses data on power-off).

## How It Works

- Each bit is stored as charge trapped on a **floating gate** — a conductive layer surrounded by insulating oxide, sitting between a [[learning/notes/micro-context/mosfet|MOSFET's]] control gate and [[micro-context/mosfet|channel]].
- **Write:** A high [[quick-context/voltage|voltage]] (~10-20V, generated by an on-chip charge pump) forces electrons through the oxide via [[quick-context/physics-of-writing-data-to-memory|Fowler-Nordheim tunneling]], trapping them on the floating gate. This shifts the [[quick-context/transistor|transistor]]'s [[micro-context/capacitive-voltage-sensing|threshold]] voltage, changing the stored bit.
- **Erase:** A reverse voltage pulls electrons back off the floating gate, resetting the bit.
- **Read:** A normal read voltage is applied to the control gate. If the floating gate holds charge, the transistor's threshold is shifted and it doesn't conduct → reads as 0. No charge → conducts → reads as 1.

```
EEPROM CELL (floating-gate MOSFET)
════════════════════════════════════════

     Control Gate ──────────────┐
                          ┌─────┴─────┐
      Oxide insulator ──► │///////////│
                          ├───────────┤
      Floating Gate ────► │  trapped  │ ← electrons stored here
                          │  charge   │
      Oxide insulator ──► │///////////│
                          ├───────────┤
      Channel ──────────► │  Si body  │
                          └─────┬─────┘
                          Source   Drain

  Write: high voltage tunnels e⁻ onto floating gate
  Erase: reverse voltage pulls e⁻ off
  Read:  charge present → threshold shifted → bit = 0
```

**[[micro-context/4-wire-kelvin-measurement|Key insight:]]** EEPROM is slow to write (~5-10 ms per byte) and has limited write cycles (~100K–1M), but it's perfect for storing small config data that rarely changes — device IDs, calibration values, or HAT identification. Flash memory uses the same floating-gate principle but erases in large blocks rather than individual bytes, trading granularity for density and [[quick-context/embedded-communication-protocols|speed]].

## Common Uses

- **Raspberry Pi HAT EEPROM:** Stores a device tree overlay telling the Pi what the board is and how to configure itself at boot (read via [[learning/notes/micro-context/i2c|I2C]] on GPIO 0 & 1)
- **[[micro-context/microcontroller|Microcontroller]] calibration:** Factory-programmed temperature sensor offsets, oscillator trim values
- **[[quick-context/data-bus-and-arbitration|Serial]] number / MAC [[quick-context/how-source-code-is-stored|address]] storage** on network devices
