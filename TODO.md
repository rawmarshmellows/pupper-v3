# Building preparations
1. Order the PCBs (see reference in the [building/pcb](building/pcb) folder)
2. Order the Bambu A2, need to figure out which filaments to use

# Building the brain    
1. Flash the PCBs by following the instructions in the [building/pcb](building/pcb) folder
2. Install Rasberry Pi 5 8gb with M.2 adapter board
3. Install the 4x4in Waveshare HDMI Raspberry Pi screen to the Raspberry Pi
4. Secure the Fisheye lens to the brain bracket using x4 M2.5x10mm 
5. Secure the control board to the brain bracket using x25 M2.5x10mm 

# Building the body
1. Connect all servos to upper body using M2.5x10mm screws
2. Secure the brain to the body
3. Connect left and right servo plugs for upper body to the control board
4. Connect the 10-pin cable to the power distribution board
5. Mount power distribution board to the body ONLY the top 2 screws
6. Connect the 10-pin cable from the power distribution board to the brain
7. Connect the 6-pin cable to the two motors for 1s
8. Mount the hip motors to the body
9. Follow the same steps for the other hip motors
10. Connect motor power control cables to the brain
11. Connect battery to brain

# Building the front legs
1. Connect the 12 inch cable to Motor ID 3 and 8 inch cable to motor ID 2
2. Attach lower leg to motor ID 3 with three M3 x 8mm screws
3. Attach upper leg to motor ID 3 with three M3 x 8mm screws
4. Repeat for other leg

# Building the back legs
1. Connect the 6 inch cable to Motor ID 1
2. Attach motor 1 to the build using 2 M2.5x10mm screws
3. Connect motor 1 to the power board
4. Repeat for other leg
5. Attach legs
