# CNC Machining

> **See also:** [[quick-context/3d-printing-filament-types]] (additive manufacturing contrast)

**Definition:** Computer Numerical Control machining is subtractive manufacturing—a computer-controlled cutting tool removes material from a solid block (metal, plastic, wood) to create a part. The opposite of 3D printing, which adds material layer by layer.

```
SUBTRACTIVE vs ADDITIVE:

CNC (subtractive):              3D Printing (additive):

  ██████████████                      ░░░░
  ██████████████    ──────►       ░░░░░░░░░░
  ██████████████    cutting       ░░░░░░░░░░░░░░
  ██████████████                  ░░░░░░░░░░░░░░░░░░
  Solid block                       Built layer by layer


CNC MILLING OPERATION:

         Spindle (rotating)
              │
           ┌──┴──┐
           │▓▓▓▓▓│  ← Cutting tool
           └──┬──┘
        chips ↓ ↓
    ══════════╧══════════  ← Workpiece (metal block)
    ══════════════════════
```

**Key insight:** CNC excels where 3D printing fails—tight tolerances (±0.001"), metal parts, and smooth surface finishes—but wastes material and can't create internal cavities without multiple setups.
