How to Play Circuit Quest

Your Mission

You're an apprentice robotics engineer. Diagnose and fix circuit problems across 5 subsystems of a broken Pupper v3 robot.

Encounters

  • Diagnosis: Read symptoms and circuit descriptions. Type what you think the problem is.
  • Repair: Select the correct component/value. Wrong choices consume inventory!
  • Tool-Required: Some actions need specific tools (Multimeter, Oscilloscope, Logic Analyzer). Actions marked with a gold border require a tool you must own.

Stats & Skill Checks

6 skills affect gameplay. Skill checks (d20 + modifier vs DC) determine success. Higher skills = better odds. Failed checks have real consequences.

Stamina Points (SP)

Spend SP for: hints (3 SP), retry failed checks (5 SP), or use class abilities (varies). Recover SP by resting between zones.

Mastery Decay

Topics decay over time. Fading topics trigger review encounters. Keep mastery strong!

Zones
